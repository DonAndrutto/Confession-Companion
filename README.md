# Confession Companion

The Vajrayana downfalls, Bodhisattva confession and Ultimate Confession in Tibetan, English and Polish, with phonetics and the alternate Polish translation. The texts, original Thirty-Five Buddhas artwork and fonts are bundled with the reader.

Run `npm ci` and `npm run dev` for local development. `npm run lint` checks TypeScript and `npm run build` creates the static site in `dist`. GitHub Actions publishes pushes to `main` to GitHub Pages.
